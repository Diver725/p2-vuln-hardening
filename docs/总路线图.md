## 1. 项目概览

| 项目 | 定位 | 技术栈 | 周期 | 状态 |

执行顺序 P1 → P2 → P3，由易到难；总周期约 3-5 个月（边上课 4-6 个月）。

## 2. 就业定位

面向央国企网安运维岗位（如国家电网），覆盖能力：
- 安全设备运维：防火墙 / IPS / WAF / 堡垒机 / 日志审计
- 等保 2.0 合规：定级、备案、差距分析、整改、配合测评
- 漏洞与基线管理：扫描、核查、加固、复测闭环
- 安全运营：SIEM 监控、告警研判、应急响应、护网蓝队值守
- 脚本自动化：Bash / Python / Ansible

每个项目 README 需沉淀三件套：技能点清单（对齐岗位 JD 关键词）、STAR 式简历描述、面试高频题与答案要点。

## 3. 环境与资源（VirtualBox · 主机内存 24GB）

- 内存规则：虚拟机设置的内存是上限，只有开机运行才占用主机内存，关机/保存状态即释放。
- 建议同时开机的虚拟机合计 ≤ 16GB，给系统与日常软件留 6-8GB。
- 典型开机组合：
  - P1 平时：pfSense 2G + Web 2G + Wazuh 8G ≈ 12G
  - P1 演练周：上表 + Kali 2G ≈ 14G
  - P2：GVM 管理机 8G + 被测机 1G×3 ≈ 11G
  - P3：Wazuh 8G + 靶机 4G + Kali 2G ≈ 14G
- 版本默认：Ubuntu Server 24.04 LTS、pfSense CE、Kali、Wazuh 单节点、雷池 WAF、GVM（Greenbone CE）、Lynis、DVWA。
- 网络模式：NAT = 安装系统/下载更新用；host-only = 实验内网（所有攻击只在这里面）。

## 4. 安全红线

1. 所有攻击流量只在 VirtualBox host-only 隔离内网，绝不扫描公网。
2. 每阶段动手前打快照（尤其加固、演练前）。
3. AI 生成的脚本先读懂逻辑，先小步测试（先 1 台）再批量。
4. 密钥 / 口令绝不入库，一律用占位符。
5. 事件模拟全部"白盒自触发"并用无害脚本，不使用真实恶意软件。

## 6. 统一作品集规范

每个项目独立 Git 仓库，目录结构：
```
README.md
architecture/    # 网络拓扑图
docs/            # 部署文档、操作步骤
scripts/         # 脚本、Ansible 剧本
configs/         # 防火墙、IDS、SIEM 等配置
screenshots/     # 实验截图
reports/         # 安全事件报告、漏洞加固报告
```

统一报告字段：事件概述 / 时间线 / 攻击路径 / IOC / 影响评估 / 处置动作 / 复盘与改进建议。
