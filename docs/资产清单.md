## 三、风险与观察
1. **暴露面小**：三台 target 全端口扫描后，仅 22/tcp（SSH）开放，其余端口均为 closed（拒绝连接）——基线较干净。
2. **SSH 版本已记录**：OpenSSH 9.6p1 (Ubuntu 3ubuntu13.19)，后续可用于与 CVE 情报比对。
3. **待改善点（后续加固项）**：
   - SSH 目前仍允许密码认证 → 建议改为密钥认证、禁用 root 直接登录、限制来源
   - 缺少 fail2ban 类登录失败封禁机制
   - 基线加固（口令策略、无用服务、SUID、审计日志）尚未执行 → 第 2-3 周处理
4. **资产清点提醒**：扫描发现的设备必须标注用途（如 .2 是 DHCP 服务器），不能只按 IP 列入业务资产。
